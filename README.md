# Sunrise Over Fuji

A make.fun entry for "One Emoji, One Dream Vacation": exactly one emoji,
nothing else, standing in for the trip of my dreams.

`main.ts` (Node 22, standard library only) writes the emoji to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> 🗻

One specific dream, not any holiday: waking before dawn to watch the sun
come up over Mount Fuji — a snow-capped mountain, a pink sky, a postcard
you can read at a glance.

Run it with `node main.ts`.
